# HANDBALL NOTE

ハンドボールのランニングスコア入力と試合分析。GitHub Pagesで動作する静的サイトです。

- チーム・背番号・結果を選び、「決定」で記録。選択内容を確認してから保存できます。詳細は後から修正できます。
- GKはその時点で守っている選手の背番号です。名簿の番号・名前ボタンから選べ、交代まで引き継ぎます。GK別セーブ率を使わない場合は未指定のまま記録できます。
- 各ハーフ30分の時刻入力・計時、前後半の得点、時刻順の累計得点。
- 修正、削除、直前の操作の取消（最大50回）。編集終了後は記録前の時計へ戻ります。
- 警告、2分退場、失格、タイムアウトを記録。これらは攻撃数に含めません。
- ブラウザ内に複数の試合を保存。JSONの保存・復元、CSVの書き出し、旧Excelの読込。
- 入力画面はiPadの動画を参考に、スコア・時間・選手・プレー・結果をひと目で操作できる配置です。
- 選手ボタンは長押ししてドラッグすると順番を変更できます。シュートや反則の発生位置は LW・L・C・R・RW から記録できます。
- シュート場所はゴール内の3×3グリッドで記録できます。以前の左・中央・右の記録も読み込めます。
- ゴールを記録すると、入力対象のチームが自動で切り替わります。
- 7mスローは、PTの理由 → 相手DFの番号（警告・退場・失格の場合）→ シューター・GK → コース・結果 → 決定の順で入力します。「ライン内」ではDF入力を省略します。結果は成功・GKセーブ・枠外の3種類です。相手DFの処分も同時に保存し、シュートとまとめて修正・取消できます。
- シュートコースに「ループ」を追加。TOを選ぶと、オーバー、ダブドリ、チャージ、ライン、パッシブ、パスカット、パスミス、キャッチミスから内容を選べます。
- 大学名簿の選択欄で「練習試合モード」を選び、反映して設定を保存すると、背番号の代わりに LW・LB・CB・RB・RW・PV・GK の7ボタンで入力できます。両チームで個別に設定でき、ポジションは記録一覧とJSON・CSVに残ります。
- 時刻を入力して「時刻を適用して再開」を押すと、その時刻から計時します。選択中のGKは、GK欄を閉じていても確認できます。
- ホームの各試合から削除できます。確認後の試合削除は取り消せません。
- 大学別名簿は `rosters.html` で登録・編集し、試合・選手設定から呼び出します。
- 元ファイルの同志社・龍谷の名簿を初期登録。新しい試合は直前の自チーム名簿を引き継ぎます。
- 試合に呼び出した名簿は独立したコピーです。名簿の更新が過去の試合を変更することはありません。

## 使い方

1. 「試合・選手設定」でチーム名・試合日を設定します。大学名簿を選び「自チームに反映」「相手に反映」→「設定を保存」。
2. 「ランニングスコア」で前後半、時刻、チーム、背番号、結果を選び、「決定」を押します。時刻は各ハーフの経過時間（00:00〜30:00）です。
3. 「試合分析」で集計を確認します。シュート失敗・ミスも記録しないと試合全体の成功率は得られません。未指定の詳細を推定・補完することはありません。
4. 試合終了時は「JSON保存」でバックアップしてください。名簿は名簿ページの「全名簿をJSON保存」で別途保存します。

G=ゴール選択、S=GKセーブ選択、O=枠外選択、B=ブロック選択、M=TO選択、V=反則選択、Enter=決定、A=自チーム、L=相手チーム。Ctrl/⌘+Z=取消。入力欄の編集中は無効です。

## 保存と互換性

データは端末・ブラウザごとの `localStorage` に保存します。サーバー同期はありません。ブラウザのデータ削除やプライベートブラウズ終了で消える場合があります。JSONは別の端末で復元できます。別タブの同時更新を検知した場合は上書きを止め、画面に案内します。

旧JSONと、`Data` / `Team` / 任意の `Personal` シートを持つ元のExcel形式を読み込めます。別形式のExcelには対応していません。元データの5分単位の時間帯は保持し、正確な時刻を捏造しません。分析・選手統計・得点の流れは毎回記録から再計算します。CSVは一覧用であり、再読込にはJSONを使います。

元のZIP・試合JSON・Python変換スクリプトはローカルに残し、公開リポジトリには含めていません。公開する初期名簿は `team-defaults.js` にあります。ここで初期名簿を変更しても、保存済みの大学名簿は上書きしません。

## 開発・確認

ビルドは不要です。Node.js 18以上でテストを実行します。

```sh
npm ci --ignore-scripts
npm test
npm start
```

pCloudなどシンボリックリンクに非対応の保存先では、インストール時に `--no-bin-links` を付けます。
ローカルURLは `http://127.0.0.1:4173/`。元の `match_data.json` がある場合は実データとの互換性テストも実行します。
テストには集計、前後半境界、編集・取消、保存・復元、名簿の登録・呼び出し、不正データ、HTMLとして解釈させない表示を含みます。DOMテストはCanvasを代替しており、ブラウザの描画品質までは検証しません。

GitHub Pagesではmainブランチのルートを公開します。ブラウザ保存の試合・名簿がGitHubへ送信されることはありません。
